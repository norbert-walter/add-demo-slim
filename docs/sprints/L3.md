```
Sprint L3, task 1 of 3. Status: L1 (types, crc32, safety_logic) and L2 (measure_logic,
params) are done and on master. Branch: sprint-l3.

- src/logic/motion_seq.h   (the documentation of motionTick is the specification)
- src/logic/types.h
- test/native/test_motion_seq/test_motion_seq.cpp and test/native/fake_axis.h
  (fake_axis.h shows how the driver reacts to each DrvOp)

Implement exactly one file: src/logic/motion_seq.cpp
- Every function declared in motion_seq.h, nothing else public.
- Use the MotionConfig fields; never hard-code its defaults (speeds, steps_per_mm, timeouts).
- Small static helpers: setPhase(s, phase, now) (also sets phase_start_ms),
  moveTo(s, target, hz) (sets s.target_steps, returns the DrvRequest), isHoming(phase).

  drv_running, (3) compute "arrived", (4) switch over the phase.

  Range checks as !(lo <= x && x <= hi) so that NaN fails them.
- Time differences: (uint32_t)(now - start) compared with the limit (wrap-around safe).
- Pure C++17: no Arduino, no heap, no static mutable state.

Run:  pio test -e native -f native/test_motion_seq

that was unclear.
```
